# 🦁 "What Would Lee Kuan Yew Do?" (LKY-AI) Chatbot

An AI-powered conversational chatbot trained on Lee Kuan Yew's public speeches, interview transcripts, and memoirs. Built for **99 Group Graduate Program AI Assessment (Section 3)** using **Streamlit** and **RAG Architecture**.

## Architecture & Features
- **Pragmatic LKY Persona**: Enforces Lee Kuan Yew's strategic, meritocratic, and highly analytical voice.
- **RAG Context Grounding**: Grounded answers using speeches and memoir transcripts (`data/lky_speeches.txt`).
- **Interactive UI**: Built with Streamlit for real-time prompt testing and multi-turn conversations.

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
